# AGENTS.md — guide for AI coding agents working on dripline

## Commands

```bash
# smoke tests (no dependencies needed)
PYTHONPATH=src python tests/test_core.py

# full test suite
PYTHONPATH=src python -m pytest tests/

# benchmarks (pinned environment — see bench/README.md)
docker run --rm --cpuset-cpus=2 --memory=8g -v "${PWD}:/bench" python:3.12-slim python /bench/bench/run.py
```

## Hard rules

- Read `CONVENTIONS.md` first. English only. Stdlib-only core; NumPy/FastAPI are
  optional extras.
- Do not touch README roadmap claims or benchmark results without the owner's
  approval; results files are generated by `bench/run.py`, never hand-edited.
- A rejected design idea belongs in `docs/adr/` (short note, why not), not in code.
- Never introduce a runtime dependency into `src/dripline` core.
- Scan the staged diff for secrets before every push.
