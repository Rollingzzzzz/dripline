2 · Single worker — apples to apples

With one worker, per-worker limiting IS global: both engines hold the budget here. The honest differences that remain: the Retry-After hint (dripline returns the exact nanosecond wait; aiolimiter returns no header). Both engines cost well under a microsecond per request — at HTTP scope the p50 differences between runs are container/network jitter, not limiter cost.
